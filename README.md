
# CS 378 — Systems-for-Generative-AI

This repository contains my implementations, notes, experiments, and
learnings while working through UT Austin's CS 378 course.

## Goals

- Understand ML systems from the hardware level upward
- Learn GPU architecture and CUDA programming
- Implement and optimize GPU kernels
- Understand PyTorch internals and performance
- Explore distributed training
- Profile and optimize ML workloads
- Complete and document all course assignments
